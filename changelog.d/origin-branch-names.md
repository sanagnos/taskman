- A local branch named `origin/main` no longer makes taskman call the default branch `remotes/origin/main` (in the Add form, in the stack hints, and in the sidebar, which then showed PRs into main as going elsewhere). Nor does it make creating a ticket's worktree fail with "ambiguous object name" where `origin/HEAD` isn't set (rarer from git 2.48, whose fetch sets it), or where the ticket's branch is only on origin and a local branch is named `origin/<branch>`.
