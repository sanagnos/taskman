- Without a remote, closing a ticket while the main checkout's HEAD is detached no longer keeps its worktree for commits that are on another branch, and a tag named like the main checkout's branch no longer makes that check fail or the Add form call the branch `heads/main`.
- A local branch named `origin/main` no longer makes taskman call the default branch `remotes/origin/main` (in the Add form, and in the sidebar, which then showed PRs into main as going elsewhere), nor, where `origin/HEAD` was never set, makes creating a ticket's worktree fail with "ambiguous object name".
