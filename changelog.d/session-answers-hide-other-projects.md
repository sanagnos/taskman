- In a session taskman started, every taskman command keeps to the session's project and no longer names the other projects: `--project` for anything but the session's own gets one refusal, the same whether that project exists, and a key with another ticket prefix gets one too, the same whether another project has the prefix. `taskman close` and `taskman resume` are now kept to the session's project as well; put `env -u TASKMAN_REPO` in front to go wider, as your permission settings decide. From your own shell the messages are as before.
