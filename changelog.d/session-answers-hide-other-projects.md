- In a session taskman started, `taskman status`, `add`, `move` and `title` no longer name the other projects or say whether there are any: `--project` for anything but the session's own project gets one refusal, the same whether that project exists, and a key with another prefix is looked up in the session's own tracker. `taskman close` and `taskman resume` errors there no longer list every project's name. From your own shell the messages are as before.
