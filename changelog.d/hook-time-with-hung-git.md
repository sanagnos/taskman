- A session's hooks keep to their time when git hangs: the git calls at a turn's end are over within 2.3 s and at a prompt's start within 0.8 s, where stopping a hung git added a quarter of a second per call (2.75 s at a turn's end, close to the 3 s at which Codex ends a hook). A slow git at a turn's end still gets 0.8 s to answer while there's time left; at a prompt's start, where it only reads the current commit, 0.55 s. A git or gh that ends when asked at its time limit no longer costs that quarter second either.
- A hook that Claude Code ends at its time limit now stops the git it was waiting for itself, whatever Claude Code's own cleanup reaches. Codex ends a hook with a signal nothing can catch, so there a hung git is stopped by the hook keeping to its time.
