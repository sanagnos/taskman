- `taskman status --json` gives a ticket's file, its worktree and the project's folder exactly as named: a name holding a zero-width, bidirectional or other invisible character used to come out without it. `taskman move`'s and the TUI's messages name a board's file exactly too (two spaces stayed one), as do the toasts that show a reply, and folder names that aren't UTF-8 print distinctly (`\xff`) instead of alike.
- Direction marks and the Hangul filler characters in tracker and PR text are kept only where right-to-left or Korean text needs them, as emoji selectors and joiners already were: elsewhere they can hide text.
