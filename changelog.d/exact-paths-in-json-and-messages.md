- `taskman status --json` gives a ticket's file, its worktree and the project's folder exactly as named: a name holding a zero-width, bidirectional or other invisible character used to come out without it. `taskman move`'s and the TUI's messages name a board's file and columns exactly too (two spaces stayed one), as do the toasts that show a reply, and folder names that aren't UTF-8 print distinctly (`\xff`) instead of alike.
- The Hangul filler characters in tracker and PR text are kept only in the Korean syllables they complete, as emoji selectors and joiners already were: elsewhere they can hide text.
- `taskman move` refuses a column name that could mean two columns (`TODO` beside `todo` and `Todo`, or `doing` beside `02-doing` and `doing`), listing them as you can type them, where it took the first; a name ending in `/` means that folder only (`doing/`); and an empty name gets its own message.
